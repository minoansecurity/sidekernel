# Security

SideKernel is in research preview. Only the latest release gets fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately via [GitHub security advisories](https://github.com/minoansecurity/sidekernel/security/advisories/new) instead.

Include what you found, how to reproduce it, and the SideKernel and macOS versions.

## Known limitations

Known limitations and risk acceptances are listed in the [README](README.md#limitations) and the [paper](https://sidekernel.com/sidekernel.pdf). Deliberate risk acceptances are not treated as vulnerabilities.
